## Try it out yourself

```bash
git clone git@github.com:itislu/42-Rush-wordle.git
cd 42-Rush-wordle
make
./wordle
```

### Requirements

- C compiler (gcc/clang)
- GNU Make
- [ncursesw library](https://invisible-island.net/ncurses/)
